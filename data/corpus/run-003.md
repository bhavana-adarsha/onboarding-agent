# Creating a New Report in PulseBoard

## Overview

PulseBoard is our primary reporting dashboard for claims, care coordination metrics, and operational KPIs. This runbook covers the process for creating a new standard report. For custom SQL queries, contact Data & Analytics.

## Prerequisites

- Active PulseBoard account with Editor role (request via Workday IT Portal)
- Access to the data source you're reporting on (ClaimsFlow, CareBridge, or TimeTrax)
- Confluence page documenting your report requirements (template: [Report Planning Template](https://confluence.meridian.local/display/ANALYTICS/Report+Planning))
- Approval from your team lead

## Step-by-Step Instructions

### 1. Log into PulseBoard

Navigate to `pulseboards.meridian.local` and authenticate with your Meridian credentials.

### 2. Create a New Report

- Click **+ New Report** (top right)
- Enter a report name following this format: `[Team]-[Metric]-[Frequency]` 
  - Example: `ClaimsOps-DenialRate-Weekly`
- Select your primary data source from the dropdown (ClaimsFlow, CareBridge, TimeTrax, or Workday)
- Click **Create**

### 3. Configure Data Fields

- In the **Fields** panel (left sidebar), select which metrics to display
- Common fields for Claims Ops: Claim ID, Status, Denial Reason, Processing Time, Provider
- Common fields for Care Coordination: Member ID, Intervention Type, Outcome, Date Assigned
- Drag fields into the **Columns** section to order them
- Click the filter icon next to each field to set default filters (e.g., Status = "Processed" only)

### 4. Set Visualization Type

- Click **Visualization** tab
- Choose your chart type: Table, Bar Chart, Line Chart, or Heatmap
- For trend analysis, use Line Chart with date grouping set to "Weekly" or "Monthly"
- For comparison, use Bar Chart with categorical grouping (e.g., by Provider or Denial Reason)

### 5. Apply Filters and Date Range

- Click **Filters** (top toolbar)
- Add date range: select **Date Range Type** → choose "Last 30 Days" or set custom dates
- Add additional filters as needed (e.g., Claims Ops team reports should filter Department = "Claims Operations")
- Save filter settings by clicking **Save Filter Set**

### 6. Configure Refresh Schedule

- Go to **Settings** → **Refresh Schedule**
- Select frequency: Hourly, Daily (recommended 2 AM), or Weekly
- Set notifications: email stakeholders when report updates
- Click **Save**

### 7. Share and Publish

- Click **Share** button
- Add team members or distribution lists (e.g., `claimsops-team@meridian.local`)
- Set permission level: Viewer or Editor
- Check "Add to Dashboard" if this report should appear on PulseBoard homepage
- Click **Publish**

### 8. Document in Confluence

- Create a page under your team's space with the report name
- Include: data source, refresh frequency, key metrics, intended audience
- Link to the PulseBoard report
- Add to relevant team wiki

## Troubleshooting

**Report shows no data:** Verify filters aren't too restrictive. Check data source connection status in Settings.

**Slow performance:** Reduce date range or add more specific filters. Contact Platform Engineering if issue persists.

**Need to modify:** Only Editors can edit. Request access or contact report owner.
